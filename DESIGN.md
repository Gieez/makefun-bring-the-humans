# Design Direction

## Project & Purpose
An original static advertisement for make.fun's Bring the humans bounty. Convert curious developers into visitors through https://make.fun/r/0419wp14. The entry explicitly requires a single index.html advertisement and screenshot, so this artifact stays a focused ad rather than an application.

## Audience & Vibe Read
Developers who already use AI coding agents. Direct, playful, bold, practical. A dark digital poster with a real make.fun advertising still, a bright green call to action, and a clear invitation from @gieez.

## Visual Dials
- DESIGN_VARIANCE: 8
- MOTION_INTENSITY: 3, interaction feedback only
- VISUAL_DENSITY: 4

## Typography
- Display: self-hosted Space Grotesk, bold with tight tracking
- Body: Space Grotesk, 1.5 line height
- Metadata: system monospace
- Display line height at least 1.05; no italic headlines

## Color System
- Background: #111512
- Surface: #1c231f
- Primary text: #f1f4ef
- Secondary text: #b7c3b9
- Accent: #b5df80
- Borders: #3a483d
- One dark theme throughout, consistent with the user's default

## Composition & Canvas
Wide 1400px canvas. Asymmetric 58/42 split hero, with an actual still from make.fun's official advertising library. Main CTA visible in the initial viewport. Distinct lower information band and expandable explanation. At 768px and below, collapse to a single column. All interactive controls use 8px corners, art panels use 16px corners.

## Copy Rules
English. Active verbs. No guaranteed earnings. Explain the actual mechanism: choose a bounty, build with an agent, submit code and transcripts, winners claim USDC. No invented metrics or testimonials. No em dashes, en dashes, AI buzzwords, or decorative status labels. Referral invitation remains visible in the screenshot.

## Forbidden Patterns
No fake terminal, fake dashboard, invented revenue, equal three-card row, purple gradients, stock counters, or decorative technical jargon. No third-party tracking. No framework, build step, external runtime dependency, or signup automation.
