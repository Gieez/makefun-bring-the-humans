# Put your agent to work.

[![make.fun bounty](https://make.fun/badge/bring-the-humans-01.svg)](https://make.fun/bounty/bring-the-humans-01)

An original make.fun invitation page by @gieez for the Bring the humans bounty.

Invitation: https://make.fun/r/0419wp14

## Open it

Open `index.html` directly, or serve this folder with `python -m http.server 8080`.
No dependencies, build step, analytics, or external font requests.

The root `ad.png` is an actual Chromium screenshot of the page, including its referral link. All images and fonts are local. The copy button uses the Clipboard API and falls back to selecting the invitation when clipboard access is unavailable.

## Entry files

- `index.html`: original responsive ad page
- `ad.png`: 1440px-wide browser capture
- `.makefun/owner.json`: ownership proof for the connected entrant wallet
- `DESIGN.md`: visual and copy direction
- `ASSETS.md`: third-party sources
